# Scoopy - Ice Cream Ordering Website 🍦

Scoopy is a responsive ice cream ordering website that allows users to choose their favorite flavor, size, toppings, and complete their order easily.

## Live Demo
https://lovely-icecream-order.lovable.app

## Features
- Browse ice cream flavors
- Choose size and toppings
- Review order before checkout
- Edit cart items
- Increase or decrease quantity
- Prices displayed in SAR
- Estimated delivery time: 20 minutes
- Order tracking page

## Technologies Used
- React
- TypeScript
- Tailwind CSS
- Lovable

## Project Idea
A web application that helps users order ice cream quickly and easily through a simple and user-friendly interface.
